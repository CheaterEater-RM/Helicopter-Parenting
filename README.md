# Helicopter Parenting

Helicopter Parenting is a RimWorld 1.6 mod that makes children's learning activities choose safer locations.

## Scope

- Floor drawing avoids dangerously cold or hot rooms when a better indoor option exists.
- Nature running avoids obviously unsafe outdoor targets, including nearby wild or hostile predators when predator avoidance is enabled.
- Sky dreaming validates or replaces unsafe outdoor spots, and if predator avoidance is enabled it also stops an active sky dream when a predator moves into range.
- Optional diagnostics logging records the mod's redirects, cancellations, and sky-dreaming interruptions for troubleshooting.

## Requirements

- RimWorld 1.6
- Harmony
- Biotech
