# Helicopter Parenting

Helicopter Parenting is a RimWorld 1.6 mod that makes children's learning activities choose safer locations.

## Scope

- Floor drawing avoids dangerously cold or hot rooms when a better indoor option exists.
- Nature running avoids obviously unsafe outdoor targets.
- Sky dreaming validates or replaces unsafe outdoor spots.

## Requirements

- RimWorld 1.6
- Harmony
- Biotech

## Status

The repository is scaffolded for implementation. See `SAFER_CHILDREN_DESIGN.md` for the original design and `DESIGN.md` for the implementation-focused engineering notes.
